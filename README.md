## 📦 Installation

### Prerequisites
- Python 3.9 or higher
- pip package manager

### Step 1: Clone Repository
```bash
git clone https://github.com/yourusername/fitburn-ai.git
cd fitburn-ai
```

### Step 2: Install Dependencies
```bash
pip install flask pandas numpy scikit-learn xgboost reportlab
```

### Step 3: Run Application
```bash
python app.py
```

### Step 4: Open Browser
```
http://127.0.0.1:5000
```

## 💻 Usage

### Calorie Prediction
1. Enter personal details (age, gender, height, weight)
2. Select exercise type & intensity
3. Input workout metrics (heart rate, duration, steps)
4. Click **"Predict Calories Burned"**
5. View results with interactive graphs
6. Download professional PDF report

### Tools Usage
| Tool | How to Use |
|------|------------|
| **Timer** | Start/Stop/Reset stopwatch, add lap times |
| **BMI Calculator** | Enter weight & height, get BMI category |
| **Calorie Counter** | Select foods or add custom items |
| **Gamification** | Complete daily tasks to earn XP |
| **AI Chatbot** | Ask fitness questions, get instant answers |
