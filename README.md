## 🛠️ Installation

### Prerequisites

```
Python 3.9+
pip (Python package manager)
```

### Step-by-Step Setup

```bash
# 1. Clone the repository
git clone https://github.com/ShumailaMaryam062/Fall-25-AI-Lab-Project.git

# 2. Navigate to project directory
cd Fall-25-AI-Lab-Project

# 3. Install dependencies
pip install flask pandas scikit-learn reportlab requests

# 4. Run the application
python app.py
```

### 📦 Required Packages

| Package | Purpose |
|---------|---------|
| `flask` | Web framework |
| `pandas` | Data manipulation |
| `scikit-learn` | Machine Learning |
| `reportlab` | PDF generation |
| `requests` | Weather API calls |

## 🚀 Usage

1. **Start the server:** `python app.py`
2. **Open browser:** Navigate to `http://127.0.0.1:5000`
3. **Enter your details:** Age, Gender, Height, Weight, Exercise Duration
4. **Get predictions:** View calorie burn estimates
5. **Explore features:** Charts, Reports, Tools & More!
